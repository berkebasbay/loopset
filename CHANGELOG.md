# Changelog

## 1.0.0-rc.9

- Publish a browser demo with deployment-subpath-aware models, world previews, fonts and sharing metadata.

- Present the product as Loopset while retaining project storage, file schema, engine and sampling identities.
- Give Factory, Festival and Service cohesive miniature surroundings, clearer selection and camera framing that respects genuine user navigation.
- Show base team availability directly; separate installed capacity, costs and shifts, and explain when the base team cannot staff all parallel stations.
- Keep full-precision numeric edit buffers behind compact reading values; unit/focus changes do not write rounded values to the model.
- Add direct scenario-to-object shortcuts, the optional three-step guide and a mobile object-editing shortcut.
- Preserve newly chosen field focus when opening desktop or mobile Properties; pending edits no longer resize the world.
- Refresh actual workspace, comparison and world-preview artwork.

## 1.0.0-rc.8

- Contextual run-length, demand, processing, waiting and team controls alongside the miniature workspace.
- Explicit preview and application of horizon changes, arrival profiles, shifts and breaks.
- Shape-preserving average edits, buffered numbers, percentage shares and field-directed repair.
- Searchable process steps, compatible group settings, safe copying and connection/insertion previews.
- Semantic input differences, named comparisons, visible saved plans and scoped bottleneck observations.
- Clear experiment purposes, finite capacity ranges, held-out verification and recorded-time navigation.
- Project, import and report workspaces; metadata-only library search; explicit CSV column/unit conversion.
- Direct identity-bound report formats, new process creation, command search and optional guidance.

## Engine 0.1.2

- Ordered waiting queues avoid repeatedly scanning blocked backlogs while preserving feasible-first dispatch semantics.
- Long and high-demand runs retain full numerical metrics independently of bounded replay.
