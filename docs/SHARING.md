# Export and share your work

## Choose the right file

| Format | Use it to |
| --- | --- |
| Project JSON | Keep an editable backup or move a project between browsers and devices. Open it through **Open project**. |
| Run JSON | Inspect a recorded calculation, including its model snapshot, seed and calculation identity. |
| Results CSV | Analyze the recorded numerical results in a spreadsheet. |
| PNG | Share a compact image with the run name, key outcomes and seed. |
| HTML | Share a self-contained report with detailed results and its model snapshot. |
| Print / PDF | Print the report or save it as PDF through the browser. |

Download an editable backup with **Download project JSON**. Open **Results → Export report** or **Files → Reports** for recorded-run exports.

## Keep the context

Reports belong to the selected recorded run. Editing the current plan does not rewrite earlier results. Cancelled, limited and failed attempts retain their incomplete status.

Check that the browser saved the actual file. A browser-library save and a file download are separate actions. Models and reports stay on your device until you share them yourself.

Review the contents before sharing a model or report containing private data. The supplied examples are synthetic; their results illustrate their assumptions rather than predict a real business.

## Share screenshots or recordings

Use current footage and retain the input assumptions and result scope. Layout and walking illustrate the process; they do not add physical transport time to the calculation.

Original code and third-party artwork have separate licences. Keep [third-party notices](../THIRD_PARTY_NOTICES.md) and [asset attributions](NVIDIA_ASSETS.md) with redistributed material.
