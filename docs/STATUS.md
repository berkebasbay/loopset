# Release status

**Loopset 1.0.0-rc.9 · model schema 1 · engine 0.1.2**

The public preview includes all three worlds, contextual and full model editing, reproducible calculations, comparisons, experiments, saved plans, project files and reports. See the [quickstart](QUICKSTART.md) to try a complete edit → calculate → compare → save/open flow.

Existing schema-1 projects and sampling identities remain compatible. Browser libraries belong to the exact site origin; use project JSON to move work between a local instance and the online demo.

Local verification covers synthetic examples, numerical contracts, actual project/report files, cancellation, keyboard/focus and desktop/tablet/phone viewport flows, with scoped Chromium, Firefox and WebKit checks. Physical-device and assistive-technology coverage and new-user studies remain separate from these checks. Reproduce the checks through [Quality](QUALITY.md).

The miniature world is illustrative. See the [model guide](MODEL_GUIDE.md) for calculation assumptions and limits, and [deployment guidance](DEPLOYMENT.md) for hosting and source identity.
