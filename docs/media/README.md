# Loopset demonstration

[Watch the 42-second demo](loopset-demo.mp4) · [Animated preview](loopset-demo.gif) · [English captions](loopset-demo.vtt)

The film shows the actual RC9 interface and calculations. In the synthetic Factory, one extra packing station leaves output unchanged until its team capacity is increased deliberately: 40 → 40 → 77 completed orders, with modeled resource cost $74 → $74 → $96. Each plan uses the same 80 modeled arrivals and seed 4207. This is one modeled case, not a validated business forecast.

The MP4 is 1920×1080 at 30 fps, silent with English captions. The lighter animated preview is derived from the same real footage. Camera closeups are editorial crops; controls, inputs and results are not invented.

Produced locally with [Hyperframes](https://github.com/heygen-com/hyperframes), with motion-direction guidance from [Cinetic](https://github.com/Leonxlnx/cinetic).
