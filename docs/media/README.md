# Loopset demos and media

[Watch both demos](https://berkebasbay.github.io/loopset/watch/) · [30-second English MP4](../../public/media/loopset-demo-short.mp4) · [55-second English MP4](../../public/media/loopset-demo.mp4)

The films combine actual Loopset footage with editorial cards and screen text. Service Studio, Festival Gate and Little Factory lead the collection. The full film also illustrates building from an empty site and saving/reusing a personal template; those graphic sections are not recordings of every corresponding UI action.

The recorded Service Studio edit changes shared specialist availability from 2 to 3, then uses the real **Run & compare** action. With the same 106 arrivals, one modeled hour and seed 4207, completed requests change from 66 to 86, average waiting from 9.5 to 5.2 minutes, and modeled resource cost from $85 to $115. Station counts, installed capacity and the break calendar stay unchanged. These rounded outcomes describe one synthetic example, not a business forecast.

Both MP4s are 1920×1080 at 60 fps with English text, music and effects. Native application images were recorded at high resolution using fixed-step browser time; this is not a real-time hardware performance benchmark. Crops and translated annotations improve readability without replacing the underlying controls or numerical results. Captions and a text walkthrough are available on the watch page. The JPEG posters are frames from these films.
